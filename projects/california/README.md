# The Entire History of California

Long-form History Monkey film, 13:51, 16:9. Made 10 November 2026 from a Gemini TTS voiceover. This folder is the worked example for `docs/PLAYBOOK.md`: copy from it when making the next film.

The full story of how it was made, with every decision the creator gave, is in `docs/sessions/2026-11-10-california.md`.

## What is in this folder

| Path | What it is |
| --- | --- |
| `script.md` | The narration script, ready to paste into Gemini TTS: one `##` heading per generation, a style line per part, supported tags only. |
| `voiceover.mp3` | The recorded voiceover, **already trimmed** (see "Audio cut" below). 13:50. |
| `voiceover.srt` | The corrected captions, timed to the trimmed voiceover. 283 lines. |
| `project.json` | Film settings: no date tag, serif captions, voice louder than effects, tech sounds on maps. |
| `tools/fix_srt.py` | Fixes the raw Gemini `.srt`: drops the cut cues, corrects 44 lines, shifts later timings. |
| `tools/make_beats.py` | Writes `beats/*.json` from the `.srt`: one beat per caption. Holds the direction tables `ERAS`, `SHOTS`, `EM`, `SFX`. |
| `beats/` | Generated by `make_beats.py`. Ten sections, all without title cards. |
| `shots.tsx` | Joins every scene file and swaps in the timeline overlay. |
| `src/Timeline.tsx` | The thin era bar across the top of the screen, which replaces chapter cards. |
| `src/Kit.tsx`, `src/Kit2.tsx` | Helpers for long films: timing by spoken word, signs, panels, the "WHO GOT RICH?" board, quiet frames, map tools, small props. |
| `src/Hook.tsx` … `src/Today.tsx` | One file per era: Hook, First (Californians), Spain, Mexico, Gold, Railroad, Sunshine, DustWar, Silicon, Today. |
| `src/qgis.json`, `src/ca.json` | Map data exported from the QGIS kit (US states, coastlines, California outline). |
| `music.json` | Music plan. Not used yet: both tracks are still "not yet heard". |

`build/` and `out/` are not in the repo (they are rebuilt).

## Rebuild the film

```
node scripts/studio.mjs doctor
python3 -I projects/california/tools/make_beats.py      # only if you changed the .srt or the tables
node scripts/studio.mjs check california
node scripts/studio.mjs stills california --section 4   # look before rendering
node scripts/studio.mjs all california                  # about 25 minutes at ~16 fps
node scripts/studio.mjs stems california                # no-voice video + voice track for the creator's own edit
```

To change one scene without re-rendering the film: find its frames in `build/timeline.json` (`shots[].from`, `dur`), render that range with `studio render california <from> <to> --out out/part.mp4`, and splice it in with ffmpeg's concat demuxer and `-c copy`. Changing caption text shifts every later beat, so re-render from that point to the end.

## Audio cut

Gemini's take repeated the Leland Stanford lines and read a heading aloud ("Chapter six. Sunshine for sale."). Both were cut from 441.0 s to 456.3 s of the original file (15.3 s), found with `silencedetect`:

```
ffmpeg -i original.mp3 -filter_complex "[0:a]atrim=0:441.0,asetpts=PTS-STARTPTS[a];[0:a]atrim=start=456.3,asetpts=PTS-STARTPTS[b];[a][b]concat=n=2:v=0:a=1[o]" -map "[o]" -c:a libmp3lame -b:a 192k voiceover.mp3
python3 -I tools/fix_srt.py original.srt voiceover.srt
```

Softer lines, worded carefully on purpose: "close to a hundred languages" (estimates 80 to 100); "tens of thousands died" in the missions; Brannan's shovels and street shouting ("the story goes"); the pig-like flag and the one-dollar egg; "nine out of every ten workers"; "more than three hundred thousand" Dust Bowl migrants (300,000 to 400,000); "another garage" for Apple. Check on the day of publishing: the home-price line and "one of the most valuable companies on Earth" (Nvidia, Santa Clara).
