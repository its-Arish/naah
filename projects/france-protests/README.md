# The French Revolution vs Today

31:48, timed to the creator's voiceover (`voiceover.mp3` + `voiceover.srt`). Twelve acts plus a cold open; 520 beats; shots in `src/Shots01.tsx` … `src/Shots12.tsx`; the France map and French scenes live in `engine/scenes/France.tsx` and `engine/scenes/FranceScenes.tsx` so other films can reuse them.

Build: `node scripts/studio.mjs all france-protests`, then `node scripts/studio.mjs stems france-protests` for the editor stems (`out/stems/`).

## Restraint

No violence is depicted: the Bastille dead, the king's execution (calendar, then black), the Terror (numbers only, no guillotine), the Commune's Bloody Week (smoke and a range of estimates), the world wars, 2005 and Nahel (places, names and dates only), and the October 2026 violence (night streets, a smouldering doorway at a distance, counters).

Real modern politicians appear only as labelled silhouettes beside paraphrased, reported statements; each camp gets the same layout. The modern sketches use fictional officials.
