# Session logs

One file per working session: what the creator asked for, in their words, what was made, and what went wrong. New sessions read these instead of relying on chat memory.

- Name files `YYYY-MM-DD-<project>.md`.
- Put standing rules in `docs/PLAYBOOK.md` (and the matching skill in `.claude/skills/`). The log only says where each rule came from.
- End every session that changes a film by updating its log and pushing.
