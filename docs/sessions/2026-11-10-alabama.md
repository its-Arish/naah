# Session log: "The Entire History of Alabama" script (10 November 2026)

Creator's request, in their words: "use naah repo from github and create script for 'the Entire History of Alabama' it should be around 20-30 minutes long".

## What was made

- `projects/alabama/script.md`: Gemini-TTS-ready script, about 4,250 words (roughly 23 to 25 minutes). Follows every rule in `docs/PLAYBOOK.md`: familiar-thing hook (Mardi Gras beads, lost suitcase, Muscle Shoals songs, Moon rocket), facts in one flow, no "stay to the end", no chapter names, headings as paste breaks, supported angle-bracket tags only, numbers spelled out, quiet-style parts for every tragedy.
- `projects/alabama/README.md`: the running thread ("five blocks" of Dexter Avenue, with a pin list), the timeline labels, a separate list of map scenes (lesson from California), the tragedy list and the fact table.

- Current events kept neutral: Space Command move worded as "announced"; Artemis II included because it has flown.
